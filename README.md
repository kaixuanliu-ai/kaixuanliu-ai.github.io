# Kaixuan Liu's academic homepage

Website: https://kaixuanliu-ai.github.io/

This is a static website published with GitHub Pages from the `main` branch, at the repository root.

## Updating the website

- Edit `index.html` to update the biography, publications, news, education, and teaching.
- Edit `styles.css` to change the layout or typography.
- Replace `assets/kaixuan-liu-portrait.webp` to update the portrait.
- Commit changes to `main`; GitHub Pages will publish them automatically.
- Keep `.nojekyll`, `robots.txt`, `sitemap.xml`, and the Google verification meta tag.

Only public website files belong in this repository. Do not add credentials or private documents.
